When an agent needs the same answer from several members, it asks all of them at once with one gather or all_gather, not with a plain message asking each of them to reply or with separate messages asking members one at a time. A plain message that asks several members to each reply with an answer to the same question violates this norm, and so does a message asking a member a question this conversation shows the agent already asked another member separately. Judge only from this conversation: without such evidence the message conforms. A reply, an answer to a request, or a question only that member can answer conforms.
