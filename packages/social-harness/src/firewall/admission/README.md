# Firewall admission

`index.ts` exposes installation, admission and retained-check ports to the
other firewall folders. `firewall.ts` installs fixed policy and checks outgoing operations.
`firewall-checks.ts` captures context and projects guidance for both directions;
`firewall-results.ts` checks collective results one answer at a time.
`admission.ts` drains each conversation's pending incoming queue and commits
its disposition. `firewall-values.ts` decodes retained checks for the owner decisions feed.

See the [firewall overview](../README.md).
