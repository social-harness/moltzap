# Built-in policy rules

Built-in rules turn captured message evidence into declared findings. The
standalone built-ins and collective-norm bundle share rule definitions, so
change their common rule rather than adding a second check in the bundle.

Review a rule change in both incoming and outgoing use. Those directions can
interpret the same evidence differently, such as an acknowledgement that needs
no reply and an outgoing acknowledgement that adds no information. Update the
recorded revision when behavior changes so retained checks identify the rule
that ran. English norms read the shipped behavior text through composition.

The [message policy contract](../../../../../docs/reference/spec/harness/message-policy.md)
owns rule meanings and the feedback a runtime may receive.
